# hacker.txt

A standardized format for communicating security-testing boundaries to ethical hackers and automated tools.

The website provides the specification, a file generator, and example websites:

- [Read the documentation](https://hackertxt.com/docs)
- [Generate a hacker.txt file](https://hackertxt.com/generator)
- [Explore example websites](https://hackertxt.com/websites)

A `hacker.txt` file can state whether testing is allowed, the authorized scope and window, permitted or excluded testing types, and security contact details.
